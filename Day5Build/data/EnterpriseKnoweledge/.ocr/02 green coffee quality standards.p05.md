A QA note on the batch record that describes a substitution but does not record the authority, the delta and the notification status is incomplete and is a finding in its own right at audit.
6. QA note taxonomy
Batch records carry free-text QA notes. Notes are classified as follows and should be written so the class is unambiguous.
| Class | Meaning | Action |
|---|---|---|
| Observation | A characteristic worth recording, no deviation | None |
| Deviation | Production departed from specification | Root cause required within five working days |
| Concession | A deviation accepted under named authority | Authority must be recorded |
| Hold | Batch not released pending investigation | Blocks despatch |
A note describing a substitution and a flatter cup profile is a deviation, and if the batch was released it is a concession, which means an authority must be recorded against it. A batch released with a deviation note and no recorded authority is a control failure whether or not the coffee was acceptable.
7. Finished-goods release
Finished goods are released when:
* the batch record is complete, including any substitution record under §5.5
* a post-roast cup has been taken and scored against the product's target profile
* any notification obligation under §5.4 has been discharged, or explicitly recorded as not applicable with a reason
Release is a positive act. A batch that nobody blocked has not been released; it has been overlooked.
8. Roast profile control
Each product has a target profile expressed as time from first crack. Profiles are held in the roasting system and are not adjusted to compensate for green quality. Roasting a flatter lot darker to mask the difference is expressly prohibited: it changes the product the customer receives while concealing the reason, and it defeats the notification obligation in §5.4 by removing the evidence a cupper would use.
