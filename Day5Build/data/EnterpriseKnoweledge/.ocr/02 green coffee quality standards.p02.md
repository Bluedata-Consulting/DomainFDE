3. Product specifications
Each product has a written specification. Production against a specification that has not been met is a deviation and is handled under §5.
3.1 Cascadia Blend (SKU MR-BLD-001)
The company's highest-volume product and the base of most subscription plans.
| Attribute | Specification |
| :---------------------------------- | :------------------------------------------ |
| Base component | Colombian washed, 60% by weight |
| Secondary component | Guatemalan washed, 25% by weight |
| Balance | Brazilian natural, 15% by weight |
| Minimum cupping score, base component | 84.0 |
| Minimum cupping score, secondary | 83.0 |
| Minimum cupping score, balance | 80.0 |
| Roast profile | Medium, first crack plus 1:45 to 2:10 |
| Target finished cup | Balanced, sweet, cocoa and stone fruit, medium acidity |
The Colombian base is what customers recognise as Cascadia. It carries the sweetness and the acidity structure. Substituting the base changes the character of the cup more than any other single change available to us, and subscription customers who have drunk it for months will notice within one bag.
